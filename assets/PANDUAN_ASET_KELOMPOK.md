# Panduan Penempatan Aset Multimedia ("PC Builder 101 — 3D Studio")

Website ini sudah dilengkapi **Engine 3D Prosedural (Three.js)**, **Web Audio Synthesizer**, **Narasi Voice-Over Otomatis**, serta **Animasi Video Canvas** sehingga dapat langsung dijalankan dan didemonstrasikan dengan membuka [`index.html`](file:///d:/download/UTS%20Multimedia/index.html).

Jika kelompok ingin memasukkan hasil rekaman suara, video, atau model 3D buatan sendiri (untuk memenuhi lampiran **File Mentah**), ikuti panduan berikut:

## 1. Folder Audio (`assets/audio/`)
Website akan otomatis memutar file `.mp3` di bawah ini jika tersedia (dan otomatis beralih ke Voice-Over Bahasa Indonesia bawaan jika file belum ada):
- `assets/audio/vo_welcome.mp3` — Rekaman sambutan Beranda
- `assets/audio/vo_mobo.mp3` — Penjelasan Motherboard
- `assets/audio/vo_cpu.mp3` — Penjelasan Processor (CPU)
- `assets/audio/vo_cooler.mp3` — Penjelasan CPU Cooler
- `assets/audio/vo_ram.mp3` — Penjelasan RAM DDR5
- `assets/audio/vo_ssd.mp3` — Penjelasan SSD NVMe M.2
- `assets/audio/vo_gpu.mp3` — Penjelasan Kartu Grafis (GPU)
- `assets/audio/vo_psu.mp3` — Penjelasan Power Supply (PSU)
- `assets/audio/vo_case.mp3` — Penjelasan Casing & Airflow

## 2. File Video (`assets/video/`)
Pada menu **🎬 Video & Audio BIOS**, terdapat tombol **"📂 Muat File .MP4 Kelompok"** yang memungkinkan kelompok memilih dan memutar video `.mp4` hasil rekaman/editan kelompok secara langsung di dalam pemutar website.

## 3. Model 3D Blender (`assets/models/`)
Pada bagian kanan atas navigasi terdapat tombol **"📦 Muat .GLB"**. Kelompok dapat mengekspor objek 3D dari **Blender** dalam format `.glb` atau `.gltf` (serta melampirkan file mentah `.blend` di folder pengumpulan UTS) lalu memuatnya langsung ke ruang 3D website!
